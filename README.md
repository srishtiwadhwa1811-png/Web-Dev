# Responsive One-Page Portfolio

A responsive one-page personal portfolio built using semantic HTML5 and modern CSS3 (Flexbox, CSS Grid, CSS custom properties, relative units, transitions, and keyframe animations).

## How to Test Responsive Breakpoints
1. Open index.html in a web browser (or run via a local/live server).
2. Open browser Developer Tools (Cmd + Option + I on Mac or F12).
3. Toggle Device Toolbar / Responsive Design Mode (Cmd + Shift + M on Mac).
4. Resize the viewport across mobile (375px), tablet (768px), and desktop (1280px+) widths to verify layout stacking, grid columns, typography scaling, and navigation behavior.
